# PingKit Agent

PingKit Agent keeps an eye on your home network from a device that stays on, and tells
[PingKit](https://pingkit.app/) when something changes. It arrives with PingKit 4.0.

This repository will hold its install files, documentation and issue tracker.

Until then, PingKit for [iPhone](https://apps.apple.com/app/id6759291812) and
[Mac](https://apps.apple.com/app/id6760315668) is on the App Store, and more is at
[pingkit.app](https://pingkit.app/).

Security reports: support@pingkit.app, as published in
[security.txt](https://pingkit.app/.well-known/security.txt).
